No tasks yet — this is real state, not the seeded playground. The usual first move is a teammate, a task, and a task-scoped mandate. 

teamplane user add --name bob --role maintainer
teamplane task create --title "first task" --repo . --verify "npm test"
teamplane mandate issue --subject BOB_ID --task TASK_ID --paths src --ttl 1h
teamplane task start TASK_ID --id MANDATE_ID

Run these from this repository. Replace BOB_ID / TASK_ID / MANDATE_ID with the ids printed by the commands. teamplane playground opens a separate seeded demo.
