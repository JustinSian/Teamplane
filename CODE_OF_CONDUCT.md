# Code of conduct

## The short version

Be direct about the work, generous about the person. This project argues about designs, threat models and evidence; it does not argue about people.

## Expected

- Critique the design, the test, or the claim — with a reproduction when possible.
- Assume the other person has read less of the code than you have, and explain the path.
- Say "I don't know" and "this is not measured" plainly. Both are encouraged here.
- Respect that security reports may need to stay private until a fix exists.

## Not tolerated

- Harassment, personal attacks, or discriminatory language.
- Publishing someone's tokens, keys, private repository contents or event logs.
- Deliberately overstating a security property in a PR, issue or review.
- Spam, or promotional posts disguised as technical discussion.

## Scope

Issues, pull requests, discussions and any project space. Maintainers may edit, lock or remove content that violates this document.

## Reporting

Email the maintainer listed on the GitHub profile, or open a private security advisory for anything sensitive. Reports are handled confidentially.

This is intentionally short. The full Contributor Covenant is a fine default; this project prefers a version people actually read.
