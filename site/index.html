Your agents share a repo, not a brain.

Teamplane gives every teammate and every agent a signed mandate, a lease on what it touches, a permissioned memory it may read, and an auditable merge gate.

Run the playground Star on GitHub
$ npm install && npm run build && npm link
$ teamplane playground --open

Three mechanisms, no supervisor

Every decision is reproducible from the event log.

01 / MANDATE

Authority is a signature

Ed25519 capabilities bound to one principal and one task. Derivation only narrows. Verification works offline; revocation is an event.

02 / GATE

Policy is a pure function

Deny > ask > allow, default deny, plus typed leases with fencing tokens. No model is consulted at decision time.

03 / EVENTS

Coordinate without transcripts

Typed events and curated memory fragments with provenance and ACLs. The team sees conclusions, not conversations.

One control plane, any MCP agent

DeepSeek Harness, Claude Code, Cursor and Codex connect over MCP — stdio or Streamable HTTP. The ten tp_* tools cover leases, memory, approvals, events and submit.

“The model keeps the interesting job — planning, coding, judgement — and loses the two jobs it is worst at: being an authority and being a lock.” docs/design-notes.md

Honest about the boundary

  • Worktree writes need the experimental host guard, not just MCP
  • Textual conflicts are verified; semantic breakage needs your tests
  • Single node, one writer, O(n) replay in v0.1
  • Per-fragment ACLs do not prevent inference from combining fragments

Read the argument
